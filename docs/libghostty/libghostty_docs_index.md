libghostty-vt - Virtual Terminal Emulator Library
libghostty-vt is a C library which implements a modern terminal emulator, extracted from the Ghostty terminal emulator.
libghostty-vt contains the logic for handling the core parts of a terminal emulator: parsing terminal escape sequences,
maintaining terminal state, encoding input events, etc. It can handle scrollback, line wrapping, reflow on resize, and
more.
  Warning
      This library is currently in development and the API is not yet stable. Breaking changes are expected in future
      versions. Use with caution in production code.
API Reference
The API is organized into the following groups:
    * Key_Encoding - Encode key events into terminal sequences
    * OSC_Parser - Parse OSC (Operating System Command) sequences
    * SGR_Parser - Parse SGR (Select Graphic Rendition) sequences
    * Paste_Utilities - Validate paste data safety
    * Memory_Management - Memory management and custom allocators
    * WebAssembly_Utilities - WebAssembly convenience functions
